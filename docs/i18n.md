# Localization (i18n)

The desktop app is localized with [vue-i18n](https://vue-i18n.intlify.dev/) (v11, composition API). One JSON
catalog per locale lives in `src/locales/<locale>.json`; **English (`en.json`) is the source of truth** — every
other catalog must carry exactly the same keys.

Available languages: `en`, `de`, `fr`, `es`, `it`, `nl`, `pl`, `pt`, `ja`, `ko`, `zh-CN`.

## How the locale is chosen

- Default is **System**: `navigator.language`/`navigator.languages` matched against the available catalogs,
  exact tag first, then language-only fallback (`de-AT` → `de`, `zh` → `zh-CN`). No match → `en`.
- The user can override it via **Settings → Language**; the choice persists in the `zebu.prefs` localStorage
  object (`language: 'system' | '<locale>'`).
- Dates, weekday/month names and numbers are formatted with `Intl` using the active locale (on "System",
  the full system tag is kept so e.g. `en-GB` retains its regional date order). See `src/i18n.ts`
  (`intlLocale`, `setLocalePreference`).

## Adding a string

1. Add the key to `src/locales/en.json` under the fitting namespace (`connect.*`, `timer.*`, `settings.*`, …).
2. Add the same key, translated, to **every** other catalog in `src/locales/`.
3. Use it: `{{ t('namespace.key') }}` in templates, `t('namespace.key')` in `<script setup>` (via
   `useI18n()`), or `i18n.global.t(...)` outside components (see `src/api.ts`).
   - Interpolation: `"Timer running since {date}"` → `t('timer.runningSince', { date })`.
   - Plurals: forms separated by `|` (`"… {n} minute | … {n} minutes"`) and selected with
     `t(key, { n }, n)`. Polish has three forms (see `pluralRules` in `src/i18n.ts`); ja/ko/zh-CN use one.
4. Run `npm run i18n:check` — it fails on missing/extra keys or `{placeholder}` mismatches against `en.json`.

Prefer `Intl.DateTimeFormat`/`toLocaleDateString` for date, weekday and month names instead of putting them
in the catalogs. Keep strings short: the popover is ~320 px wide, and German/French run long.

## Adding a language

1. Copy `src/locales/en.json` to `src/locales/<locale>.json` (BCP-47 code, e.g. `sv` or `pt-BR`) and translate
   every value. The file is picked up automatically (`import.meta.glob` in `src/i18n.ts`).
2. Add the language's native name to `LOCALE_NAMES` in `src/i18n.ts` (shown in the Settings picker).
3. If the language has non-trivial plural rules (like Polish or Russian), add an entry to `pluralRules` in
   `src/i18n.ts` and give plural-aware messages the right number of `|`-separated forms.
4. Run `npm run i18n:check`.

## Tray strings

The menubar tooltip is formatted in the frontend (`tray.*` keys) and passed to Rust through the
`set_tray_state` command's `tooltip` field, so it follows the app locale. The `{time}` placeholder must stay
literal in every locale: Rust's tray ticker substitutes the elapsed time on each minute rollover (the
frontend cannot, as webview timers stall while the popover is hidden). The idle pill text `zzzz` is a brand
mark, not a word — never translate it.
